# 스프링 MVC 2편

## 타임리프(Thymeleaf) 기본 기능과 레이아웃

### 타임리프의 핵심 특징: SSR과 네추럴 템플릿

타임리프는 백엔드 서버에서 HTML을 동적으로 렌더링하는 **SSR(Server-Side Rendering)** 템플릿 엔진이다. JSP 등 기존 템플릿 엔진과 차별화되는 타임리프만의 가장 강력한 강점은 **네추럴 템플릿(Natural Templates)** 이다.

| 구분 | JSP / 기타 템플릿 엔진 | 타임리프 (Thymeleaf) |
| ------ | ------ | ------ |
| **파일 구조** | HTML 마크업과 서버 스크립틀릿(`<% ... %>`)이 뒤섞임 | 순수 HTML 문법 규격을 그대로 유지 (`th:*` 속성 방식) |
| **로컬 브라우저 실행** | 서버 렌더링 없이 직접 열면 파싱 에러 발생 또는 깨짐 | 웹 브라우저에서 직접 열어도 정상적인 프로토타입 화면 노출 |
| **동적 렌더링 방식** | 서버 엔진을 통해서만 결과 확인 가능 | 웹 브라우저는 알지 못하는 `th:*` 속성을 무시하고 원본 HTML 렌더링 |
| **협업 생산성** | 퍼블리셔와 백엔드 개발자 간 파일 파편화 발생 | 하나의 템플릿 파일로 마크업 검수와 동적 렌더링 동시 해결 |

### 텍스트 출력과 이스케이프(Escape) 매커니즘

HTML 문서는 `<`, `>` 같은 특수 문자를 기반으로 태그를 파싱한다. 사용자가 입력한 데이터에 HTML 특수 문자가 포함되어 있을 때 이를 문자 그대로 안전하게 표현하기 위해 HTML 엔티티로 변환하는 과정을 **이스케이프(Escape)** 라고 한다.

*   `th:text` / `[[...]]` : 기본적으로 이스케이프가 자동 적용된다. `<`는 `&lt;`, `>`는 `&gt;`로 변환되어 악의적인 스크립트 실행(XSS)을 방지한다.
*   `th:utext` / `[(...)]` : 이스케이프를 해제(Unescape)하고 실제 HTML 태그로 해석하여 렌더링한다. (보안상 꼭 필요한 경우에만 제한적으로 사용).

```html
<!-- Controller: model.addAttribute("data", "Hello <b>Spring!</b>"); -->
<ul>
    <li>th:text = <span th:text="${data}"></span></li>      <!-- 출력: Hello &lt;b&gt;Spring!&lt;/b&gt; -->
    <li>th:utext = <span th:utext="${data}"></span></li>    <!-- 출력: Hello <b>Spring!</b> (진하게 렌더링) -->
</ul>
```

### SpringEL 변수식과 스프링 부트 3.0 변경사항

타임리프는 `${...}` 문법을 통해 스프링의 **SpringEL(Spring Expression Language)** 을 완벽하게 지원한다.

*   **Object 프로퍼티 접근** : `${user.username}` -> `${user['username']}` -> `${user.getUsername()}` 프로퍼티 게터 호출.
*   **List 인덱스 접근** : `${users[0].username}` -> `users.get(0).getUsername()`.
*   **Map 키 접근** : `${userMap['userA'].username}` -> `userMap.get("userA").getUsername()`.
*   **지역 변수 선언** : `th:with="first=${users[0]}"` (선언된 태그 내부에서만 유효).

#### 스프링 부트 3.0 (Spring 6.0) 핵심 주의사항

스프링 부트 3.0부터는 보안 및 아키텍처 정비로 인해 타임리프 기본 식 객체인 `${#request}`, `${#response}`, `${#session}`, `${#servletContext}`를 기본 제공하지 않는다.
대신 스프링 부트가 제공하는 **편의 객체**를 사용하여 직관적으로 접근한다:
1.  **HTTP 요청 파라미터 접근** : `${param.paramData}`
2.  **HTTP 세션 데이터 접근** : `${session.sessionData}`
3.  **스프링 빈 직접 접근** : `${@helloBean.hello('Spring!')}`

### 유틸리티 객체와 URL 링크 문법

자바8 날짜 객체(`LocalDate`, `LocalDateTime`)를 다루기 위해 `thymeleaf-extras-java8time` 라이브러리가 기본 통합되어 있으며, `#temporals` 객체를 사용한다.
```html
<!-- 날짜 포맷팅 출력 -->
<span th:text="${#temporals.format(localDateTime, 'yyyy-MM-dd HH:mm:ss')}"></span>
```

#### URL 링크 표현식 `@{...}`
*   **단순 URL** : `@{/hello}` -> `/hello`
*   **쿼리 파라미터** : `@{/hello(param1=${p1}, param2=${p2})}` -> `/hello?param1=data1&param2=data2`
*   **경로 변수(PathVariable)** : `@{/hello/{p1}/{p2}(p1=${p1}, p2=${p2})}` -> `/hello/data1/data2`
*   **경로 변수 + 쿼리 파라미터 조합** : `@{/hello/{p1}(p1=${p1}, param2=${p2})}` -> `/hello/data1?param2=data2`

### 리터럴, 연산자, 그리고 No-Operation
*   **리터럴 대체(Literal Substitutions)** : `|hello ${data}|` 문법을 사용하면 따옴표와 `+` 연산자 결합 없이 템플릿 문자열을 직관적으로 작성할 수 있다.
*   **Elvis 연산자** : `${data}?: '기본값'` (데이터가 null이면 기본값 출력).
*   **No-Operation (`_`)** : `${data}?: _` 연산 결과가 `_`인 경우, 타임리프 태그가 실행되지 않은 것처럼 원본 정적 HTML 태그의 텍스트가 그대로 보존된다.

### 태그 제어와 자바스크립트 인라인

*   `th:classappend` : 기존 클래스 속성에 공백을 두고 자연스럽게 신규 클래스를 추가한다.
*   `th:checked` : HTML 표준 체크박스는 `checked="false"`로 명시되어도 속성이 존재하면 체크된다. 타임리프의 `th:checked`는 값이 `false`이면 HTML의 `checked` 속성 자체를 제거하여 언체크 상태를 유지한다.
*   `th:each="user, userStat : ${users}"` : 반복 루프를 실행하며 상태 객체(`index`, `count`, `size`, `even`, `odd`, `first`, `last`)를 조회할 수 있다.
*   `th:if`, `th:unless` : 조건이 false이면 해당 HTML 태그 자체를 DOM 렌더링에서 제거한다.
*   `<th:block>` : HTML 태그를 생성하지 않고 타임리프 로직(`each`, `if` 등)만 묶어서 실행할 때 사용하는 유일한 자체 가상 태그이다.

#### 자바스크립트 인라인 `<script th:inline="javascript">`

인라인 기능을 적용하면 웹 브라우저 환경에서 발생할 수 있는 스크립트 문법 오류를 완벽히 차단한다:
1.  **문자 타입 자동 인용부호 처리 및 이스케이프** : `var username = "userA";` (`"` 및 특수문자 자동 이스케이프).
2.  **자바스크립트 내추럴 템플릿** : `var username2 = /*[[${user.username}]]*/ "test";` -> 순수 파일로 열면 `"test"`, 서버 렌더링 시 `"userA"`로 대체.
3.  **객체 JSON 자동 직렬화** : `var user = [[${user}]];` -> `var user = {"username":"userA","age":10};` 객체를 JSON 포맷으로 자동 변환.

### 템플릿 조각(Fragment)과 레이아웃 확장

반복되는 헤더, 푸터, 네비게이션 바 등의 공통 UI 코드를 조각으로 모듈화한다.

```
[템플릿 포함 방식 차이]
th:insert="~{template/fragment/footer :: copy}"  -> 현재 태그 내부에 조각을 자식 태그로 삽입
th:replace="~{template/fragment/footer :: copy}" -> 현재 태그 자체를 대상 조각 태그로 완전히 대체
```

#### `<html>` 태그 기반 레이아웃 상속
공통 베이스 레이아웃을 정의하고, 실제 페이지에서는 `<html>` 태그 자체를 `th:replace`로 대체하면서 필요한 타이틀과 섹션 영역만 조각 표현식(`~{::title}`, `~{::link}`, `~{::section}`)으로 파라미터 전달하여 화면을 조립하는 방식을 실무에서 널리 활용한다.
